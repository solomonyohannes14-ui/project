# MediBridge

MediBridge is a Next.js application scaffold for a patient-facing health
records portal.

## Getting started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

The route, service, and data directories are scaffolding; connect them to a
backend before using them with real patient information.
